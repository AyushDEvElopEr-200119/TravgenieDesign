# TravGenie — Corporate Business Travel

TravGenie is an enterprise corporate travel platform for booking policy-compliant flights and hotels with negotiated company fares, travel policy approvals, and spend tracking.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start)
- **UI Library**: React 19
- **Styling**: Tailwind CSS v4
- **State & Data Fetching**: TanStack Query & TanStack Router
- **Icons**: Lucide React
- **Component Primitives**: Radix UI

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

The application will be available at `http://localhost:8080`.

### Building for Production

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
